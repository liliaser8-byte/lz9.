## ЗАВДАННЯ 1.

13.Створити однозв’язний список із дійсних чисел. Вставте перший додатний елемент
списку після кожного від’ємного числа (якщо такого немає — залиште список без
змін).

### Код

```cpp
#include <iostream>
#include <forward_list>

using namespace std;

int main() {
    forward_list<double> numList;

    // Додавання дійсних чисел до списку (push_front додає елементи на початок)
    numList.push_front(4.2);
    numList.push_front(-1.5);
    numList.push_front(0.0);
    numList.push_front(-7.8);
    numList.push_front(3.5);
    numList.push_front(-2.1);
    
    cout << "Початковий список дійсних чисел: ";
    for (double n : numList) {
        cout << n << " ";
    }
    cout << endl;

    // 1. Пошук першого додатного елемента (> 0)
    double firstPositive = 0.0;
    bool hasPositive = false;

    for (double n : numList) {
        if (n > 0) {
            firstPositive = n;
            hasPositive = true;
            break;
        }
    }

    // 2. Вставка знайденого елемента після кожного від'ємного (< 0)
    if (hasPositive) {
        for (auto it = numList.begin(); it != numList.end(); ++it) {
            if (*it < 0) {
                // insert_after вставляє значення після поточного ітератора 
                // і повертає ітератор на щойно доданий елемент
                it = numList.insert_after(it, firstPositive);
            }
        }
    } 
    cout << "Список після обробки: ";
    for (double n : numList) {
        cout << n << " ";
    }
    cout << endl;

    return 0;
}
```

Програма створює однозв’язний список дійсних чисел (`std::forward_list<double>`), знаходить у ньому перше додатне число та вставляє його копію після кожного від’ємного елемента. Якщо додатних чисел у списку немає, програма залишає його без змін.

**Як працює програма (покроково):**

1. **Заповнення списку:** Числа додаються на початок списку методом `push_front()` (через це в самому списку вони йдуть у зворотному порядку до того, як записані в коді), після чого початковий список виводиться на екран.
2. **Пошук першого додатного елемента:** Цикл `for` послідовно перевіряє елементи, доки не знайде перше число, більше за `0`. Воно записується у змінну `firstPositive`, прапорець `hasPositive` отримує значення `true`, а пошук одразу зупиняється оператором `break`. Якщо додатних чисел немає, `hasPositive` залишається `false`.
3. **Вставка після від’ємних чисел:** Якщо додатне число знайдено (`hasPositive == true`), програма проходить по списку за допомогою ітератора `it`. Коли зустрічається від’ємний елемент (`*it < 0`), метод `insert_after()` вставляє значення `firstPositive` одразу після нього. Конструкція `it = numList.insert_after(...)` переводить ітератор на щойно доданий елемент, щоб уникнути його зайвої перевірки на наступному кроці.
4. **Виведення результату:** Програма виводить змінений (або початковий, якщо додатних чисел не було) список у консоль.

## ЗАВДАННЯ 2. 

13.Створити список вартостей покупок. Видаліть усі значення, менші за 10.

### Код

```cpp
#include <iostream>
#include <forward_list>
#include <iomanip>

using namespace std;

int main() {
    forward_list<double> prices;

    // Додаємо вартості покупок до списку
    prices.push_front(15.50);
    prices.push_front(8.20);
    prices.push_front(24.00);
    prices.push_front(5.99);
    prices.push_front(10.00);
    prices.push_front(42.75);

    cout << "Початковий список вартостей покупок: ";
    for (double price : prices) {
        cout << setprecision(2) << fixed << price << " ";
    }
    cout << endl;

    // Формуємо новий список без значень, менших за 10
    forward_list<double> result;
    for (double price : prices) {
        if (price >= 10.0) {
            result.push_front(price);
        }
    }

    cout << "Список після видалення значень < 10: ";
    for (double price : result) {
        cout << setprecision(2) << fixed << price << " ";
    }
    cout << endl;

    return 0;
}

```

Програма створює однозв’язний список вартостей покупок (`std::forward_list<double>`), відфільтровує його, залишаючи лише значення, не менші за `10.0`, та виводить початковий і результуючий списки у форматі з двома знаками після коми.

**Як працює програма (покроково):**

1. **Заповнення списку:** Вартості покупок додаються на початок списку `prices` методом `push_front()` (через це в самому списку вони розташовуються у зворотному порядку відносно того, як записані в коді).
2. **Виведення початкового списку:** Цикл `for` послідовно перебирає елементи `prices` і виводить їх на екран за допомогою маніпуляторів `setprecision(2)` та `fixed`, що забезпечує відображення двох знаків після дробової крапки.
3. **Фільтрація значень:** Створюється новий порожній список `result`. Програма проходить по всіх елементах початкового списку `prices` і перевіряє умову `price >= 10.0`. Якщо вартість більша або дорівнює `10`, вона додається до `result` методом `push_front()`, а всі значення, менші за `10`, пропускаються.
4. **Виведення результату:** Отриманий список `result` без значень, менших за `10`, виводиться у консоль у тому самому форматі.
